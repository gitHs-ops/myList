손그림 → 3D 도면 프로토타입

치수가 적힌 손그림 스케치를 올리면 벽체를 3D로 세워줍니다. 비전 API 없이도 아래 샘플/JSON으로 파이프라인을 바로 확인할 수 있습니다.

💰 이번 세션 비전 API ≈ $0 · 토큰 입력0/출력0

1 스케치 업로드

이미지를 끌어놓거나 클릭해서 선택 (여러 장 가능)
백엔드 설정

GitHub Pages(프론트) + Render(백엔드) 구조. 백엔드가 없어도 아래 3·5번(JSON/샘플)은 동작합니다.
접근 코드는 이 브라우저에만 저장됩니다.

2 대화로 수정 (API 필요)

현재 3D 모델을 말로 고칩니다. 우측 화면을 보며 조정하세요.
예: “왼쪽 벽을 1000mm 늘려줘”, “가운데 칸막이벽 추가”, “위쪽 벽 지워”, “벽 두께 300으로”

3 벽 좌표 JSON

단위 mm · 평면 좌표 [x, y] (원점 좌하단, x→오른쪽, y→위). 벽은 중심선 기준.
벽 옵션: height · thickness · sill/lintel(벽 전체폭 밴드).
가로 창/문: openings:[{offset, width, sill, height, type}] — offset=벽 시작점~개구부, width=폭.
방 이름표: rooms:[{label, point:[x,y]}] — point는 그 방 안쪽 아무 좌표.

4 인허가용 정식 도면

평면도 + 4방위 입면도를 축척·방위·치수가 표기된 A3 인쇄용 시트로 구성해 새 창에 엽니다. 인쇄 대화상자에서 "PDF로 저장"(배율 100%)을 선택하세요.
주의: 본 기능이 만드는 도면은 손그림 스케치 기반 자동 생성 초안입니다. 실제 인허가 제출 전 반드시 건축사의 검토·날인이 필요합니다.
