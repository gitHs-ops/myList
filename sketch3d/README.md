# sketch3d — 손그림 → 3D 벽체 프로토타입

치수가 적힌 손그림 스케치를 올리면 벽 좌표를 인식해 Three.js로 3D 벽체를 세운다.
영덕감성산장 객실 동 인허가 도면 작업을 계기로 한 셀프 건축주용 웹앱 MVP.

## 구조
- `index.html` — 프론트엔드 (GitHub Pages 배포용, 순수 HTML/JS + Three.js CDN)
- `server/` — Extract API (Express + Claude Vision, Render 배포용)

3D 파이프라인은 **비전 API 없이도** 샘플/JSON 입력으로 바로 확인 가능 (index.html 2·3번).

## 로컬 실행
```bash
cd sketch3d/server
cp .env.example .env      # ANTHROPIC_API_KEY 채우기
npm install
npm start                 # http://localhost:8787
```
프론트는 `index.html` 을 브라우저로 열면 됨. 백엔드 URL 기본값은 `http://localhost:8787/api/extract`.

## 데이터 포맷 (벽 좌표 JSON)
```json
{
  "unit": "mm",
  "wallHeight": 2700,
  "wallThickness": 200,
  "walls": [
    { "start": [0, 0], "end": [5000, 0] }
  ],
  "notes": "치수 없는 부분은 비율로 추정"
}
```
- 좌표계: 원점 좌하단, x→오른쪽, y→위, 단위 mm
- 벽은 중심선 `start`~`end` 선분

## 가구 배치

3D 뷰(`.viewport-card`) 상단의 "🛋️ 가구 배치 모드" 버튼이 캔버스에서 가구 배치·제거·
이동이 동작할지를 켜고 끈다(꺼져 있으면 캔버스는 평소처럼 카메라 회전/줌만 함). 옆
드롭다운에서 타입을 고르면 모드가 자동으로 켜지고, 바닥을 클릭하면 그 자리에 배치된다
(드롭다운은 선택한 타입을 계속 보여줘 연속 배치 가능). 드롭다운을 placeholder로
되돌리면 배치 대기만 풀리고 모드는 유지되며(배치된 가구 클릭/드래그는 계속 됨), 토글
버튼을 다시 누르면("🛋️ 가구모드해제") 모드 전체가 꺼진다. 배치된 가구를 클릭하면
armed 여부와 무관하게 항상 확인창(브라우저 기본 confirm)을 띄운 뒤 확인해야 제거되고,
드래그하면 그 방향으로 옮겨진다. 놓으려는 자리가 벽 밖으로 나가거나 다른 가구와
겹치면, 배치는 그 위치에 아예 놓지 않고 거부하지만 드래그 이동은 시작 위치로 전부
되돌리는 대신 그 방향으로 갈 수 있는 가장 먼 지점까지만 이동한다(벽이나 가구에 딱
붙는 위치) — 가구 전체(중심점이 아니라 폭·깊이 기준 외곽)를 기준으로 판정하므로, 예를
들어 큰 소파를 벽에 너무 가깝게 놓거나 다른 가구 위에 겹쳐 놓을 수 없다. 벽 판정은
정확한 방 폴리곤이 아니라 전체 벽 중심선 바운딩박스를 벽 두께의 절반만큼(중심선에서
내측면까지) 줄인 사각형으로 근사하므로, 오목한(L자) 평면에서는 완벽하지 않다. 1인칭
시점과는 동시에 켤 수 없다(가구 모드를
켜거나 가구를 선택하면 1인칭이 꺼지고, 1인칭을 켜면 배치 모드가 꺼진다). 이름표는
가구 높이와 무관하게 항상 고정 크기로 가구 상단에 표시되지만, 인허가용 정식 도면과
평면도·입면도(도면 생성)에는 가구가 아예 나오지 않는다(3D 뷰에서만 보임). 회전은
가구를 선택했을 때 위쪽 모서리에 나타나는 파란 손잡이를 마우스로 드래그해 90도 단위로만
할 수 있다(아래 문단에서 자세히 설명) — 자유각(45도 등)은 지원하지 않는다. 대부분은 육면체 하나지만, `steps` 값이 있는 타입(계단)은
그만큼의 박스를 층층이 쌓아 계단 실루엣으로 표시한다(전체 폭·깊이·높이는 여전히 하나의
바운딩박스로 취급 — 배치·이동·충돌 판정에 영향 없음). 모델을 다시 만들어도(샘플 선택,
JSON 재생성 등) 배치는 유지된다. 한꺼번에 지우는 기능은 없어 하나씩 클릭해서 제거해야
한다. 타입별 기본 크기는 `index.html`
의 `FURNITURE_TYPES`. 단위 mm.

이미 배치된 가구의 치수를 바꾸려면 아래 "채팅으로 모델 수정"의 크기 지시를 쓴다
(배치 자체는 늘 스키마 기본 크기로 이뤄진다 — 배치 시점에 크기를 다르게 지정하는
기능은 없음).

마우스 드래그는 위치를 대략 맞추기엔 좋지만 정확히 맞추긴 어렵다 — 방금 배치했거나
드래그로 옮긴(벽/충돌로 되돌려졌더라도) 가구 하나가 자동으로 "선택" 상태가 되어
테두리가 노란색으로 강조되고, 이 상태에서 **Shift+화살표**를 누르면 그 방향으로
10mm씩 미세 이동한다(↑↓은 z축, ←→는 x축). 벽 밖으로 나가거나 다른 가구와 겹치면
그 키 입력만 무시되고 자리는 그대로다(드래그처럼 되돌릴 필요 자체가 없음). 선택은
가구 모드를 끄면(🛋️ 가구모드해제) 해제되고, 입력창(채팅·JSON 등)에 포커스가 있을
때는 화살표가 원래 하던 일(커서 이동 등)을 그대로 한다.

선택된 가구의 앞쪽-오른쪽 위 모서리(로컬 +x,+z, 맨 위) 바로 바깥에는 작은 파란 구(회전
핸들)가 나타난다. 이 핸들을 마우스로 눌러 드래그하면, 가구 중심에서 지금 커서가 가리키는 바닥 지점 쪽으로 가구
전체가 회전한다 — 자유각이 아니라 항상 가까운 90도 단위(0/90/180/270도)로 스냅되고,
드래그 중에도 그 스냅된 모습 그대로 보인다. 놓았을 때(마우스 버튼을 뗄 때) 그 방향이
벽 밖으로 나가거나 다른 가구와 겹치면 회전 자체를 취소하고 원래 방향으로 되돌린다(위치
이동과 달리 "갈 수 있는 데까지" 같은 중간값은 없음 — 90도 단위 4가지뿐이라 되거나
안 되거나 둘 중 하나). 90도·270도로 회전하면 가구의 가로·세로가 실제로 맞바뀌므로(정사각형이
아닌 가구는 발밑 점유 영역이 달라짐) 벽·다른 가구와의 판정도 항상 그 맞바뀐 크기를
기준으로 한다. 핸들은 가구가 선택돼 있을 때만 보이고 클릭할 수 있으며, 마우스를 올리기만
해도(클릭 전) 상태 표시줄에 "회전"이라고 잠깐 뜬다(벗어나면 그 전 표시로 복원). **채팅으로
모델 수정(아래)으로는 회전할 수 없다** — 회전은 이 마우스 드래그로만 가능하다.

| 타입 | width(가로) | depth(세로) | height(높이) |
|---|---|---|---|
| 싱크대 (`sink`) | 1000 | 600 | 850 |
| 침대 (`bed`) | 1500 | 2000 | 450 |
| 싱글침대 (`bedSingle`) | 1200 | 1800 | 450 |
| 소파 (`sofa`) | 2000 | 900 | 850 |
| 식탁 (`table`) | 1200 | 800 | 750 |
| 사무용탁자 (`desk`) | 1200 | 600 | 720 |
| 냉장고 (`fridge`) | 800 | 750 | 1750 |
| 3단계단 (`stairs3`) | 500 | 600 | 900 |
| 6단계단 (`stairs6`) | 500 | 600 | 1500 |

## 채팅으로 모델 수정

3D 뷰 옆 채팅창(`chatInput`/`보내기`)에 한국어로 지시를 쓰면 `server/`의 `/api/edit`이
Claude로 현재 모델을 고쳐 돌려준다(백엔드 설정에서 API URL·접근 코드 필요, `/api/extract`
와 같은 서버). 되돌리기/다시하기(↩/↪)로 직전 상태로 왕복할 수 있다.

- **벽체**: "왼쪽 벽을 1000mm 늘려줘", "가운데 칸막이벽 추가", "위쪽 벽 지워", "벽 두께
  300으로", "북쪽을 오른쪽으로", "박공지붕 물매 30도", "왼쪽 방을 침실로" 등 — 벽·개구부·
  지붕·방 이름표·north 를 좌표/스키마 그대로 반영해 돌려준다.
- **가구 크기(신규)**: "싱크대 가로 1000으로", "소파 깊이 900으로 줄여줘", "냉장고 높이
  200 늘려줘"처럼 **이미 3D에 배치된** 가구의 가로(width)/세로·깊이(depth)/높이(height)
  중 언급된 치수만 절대값 또는 가감으로 바꾼다. 배치·삭제·이동은 이 채팅이 아니라 3D
  화면 직접 클릭·드래그(위 "가구 배치")로만 한다 — 채팅에 그런 지시를 하면 notes로
  안내만 하고 배열은 건드리지 않는다. **회전은 이 채팅으로는 안 된다** — 3D 화면에서
  가구를 선택하면 나타나는 파란 손잡이를 마우스로 드래그해야만 회전할 수 있다(위 "가구
  배치" 참고). 같은 타입이 여러 개
  배치돼 있고 어떤 것인지 특정하지 않으면 전부에 같은 값이 적용된다. 아직 배치된
  항목이 없는 타입을 지시하면 반영할 대상이 없다고 notes에 남긴다(스키마 기본값
  자체를 바꾸는 기능은 아니다).
- 되돌리기/다시하기는 벽과 가구 상태를 함께 스냅샷으로 묶어 왕복한다(가구 크기수정·
  회전을 되돌리면 그 값도 같이 원복). 채팅 수정·되돌리기·다시하기는 전부 카메라 위치·시점을
  그대로 유지한다 — 보고 있던 각도·확대 상태에서 바뀐 부분만 다시 그려진다(샘플 선택·
  JSON 새로 적용·비전 인식·프로젝트 불러오기처럼 아예 다른 모델을 보여줄 때만 카메라를
  새로 맞춘다).

## 배포
- 프론트: GitHub Pages → `https://giths-ops.github.io/myList/sketch3d/`
- 백엔드: Render → `https://mylist-9nha.onrender.com` (Web Service 수동 생성, Root Directory `server`, 환경변수 `ANTHROPIC_API_KEY`/`VISION_MODEL`). 프론트 기본 Extract API URL이 이 주소로 설정되어 있음(`/api/extract`).
- `server/server.js`를 고친 뒤(`/api/edit` 스키마·프롬프트 등) 실제 배포본에 반영하려면 이 Render 서비스가 새 커밋을 반영해 재배포돼야 한다 — 로컬에서 `npm start`로 확인해도 배포본은 별개로 재배포 전까지 이전 코드 그대로다.
